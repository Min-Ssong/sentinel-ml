## 해석 (2026-10-18 15:5x KST 작성)

### 원본: 두 모델은 동등하다고 본다
- 같은 거래 Recall: 챔피언 1319 / 1621 = 0.8137, 챌린저 1337 / 1621 = 0.8248, 차이 18건(+0.0111).
- 95% 구간이 겹친다 (챔피언 상한 0.8319 > 챌린저 하한 0.8055).
- 불일치 26건(5 vs 21)에 McNemar 정확검정을 하면 p ≈ 0.0025 이지만 **근거로 쓰지 않는다**. 사기 거래는 holdout 사기 75행의 반복 추출이라 서로 독립이 아니고, 실제 독립 표본은 75행이다.
- 두 값은 10/5 오프라인 holdout 결과(v12 61/75 = 0.8133, 같은 데이터·설정의 드리프트 재학습 모델 62/75 = 0.8267)와 거의 같다. 차이가 사기 원본 행 1개에서 나왔을 가능성과 맞지만, 불일치 18건이 어떤 원본 행인지는 확인하지 않았다.
- 결론: 원본 분포에서 챌린저가 낫다고 말할 근거는 없다. 이 구간만으로는 승격 근거가 되지 않는다.

### S2: 챌린저 우세는 예상된 결과다
- 같은 거래 Recall: 챔피언 594 / 1634 = 0.3635, 챌린저 1560 / 1634 = 0.9547, 차이 +0.5912.
- 95% 구간이 겹치지 않는다 (챔피언 상한 0.3871 < 챌린저 하한 0.9435). 불일치 969건 중 966건은 챌린저가 맞았다.
- v16은 `sentinel_retrain_drift`로 원본 학습 풀에 S2 변형 사기 행 417건을 더해 학습한 시연용 버전이다. S2 패턴을 학습한 모델이 S2 트래픽에서 이긴 것이다. 따라서 "Shadow로 더 좋은 모델을 찾았다"는 근거가 아니다. **드리프트 재학습 → Shadow 비교 → 승격 판단이 같은 거래 기준으로 동작한다**는 근거다.
- 수치는 10/5 오프라인 실험(챔피언 27/75 = 0.36, 같은 설정 챌린저 72/75 = 0.96)과 같은 수준이다.

### 공통
- Precision: FP는 5~8건, 정상 거래는 2,374~2,420건이다. 시뮬레이터 사기 비율이 0.5라서 실제 운영 수준의 Precision이 아니다.
- C. 룰 차단 거래의 챌린저 Recall(원본 0.8307, S2 0.9487)은 같은 거래 비교 값(0.8248, 0.9547)과 구간이 겹친다. 10/7 SD6의 추론("룰은 피처와 무관해 모집단 차이로 인한 Recall 편향이 크지 않다")과 맞는 관찰이다.
- 다만 룰 차단 거래 818~822건 중 정상은 3~4건뿐이다. 룰 차단 모집단의 정상 거래 쪽 비교(FP)는 할 수 없다.
- Prometheus 지표(`promote_challenger.py status`)는 챔피언·챌린저 모집단이 달라서 이 리포트처럼 같은 거래를 비교하지 못한다. 승격 판단에는 이 리포트를 근거로 쓴다.
